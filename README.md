# ReserVite

ReserVite is a restaurant reservation and management application developed as a group project during my Bachelor's degree in Application Development at EPFC (Brussels).

The application allows customers to search for restaurants and make reservations, while restaurant managers can manage their bookings, tables and services.

## Technologies

- **Language:** Dart
- **Framework:** Flutter
- **Database:** PostgreSQL
- **API:** PostgREST
- **Architecture:** MVC (Model-View-Controller)
- **State management:** Riverpod

## Features

- User registration and login
- Restaurant search and detailed information
- Creation, modification and management of reservations
- Reservation history and details for customers
- Reservation management for restaurant managers
- Table assignment and management
- Restaurant services management
